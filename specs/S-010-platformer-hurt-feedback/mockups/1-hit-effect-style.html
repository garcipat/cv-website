Which hit-effect style fits the game?

Each panel loops: idle → hit → recover, using the actual knight.png / slime_green.png sprites. Option C (blood/goo splatter) is the one that was picked — see mockup 3 for the final, tuned version.

A. Stylized burst

Small pixel spark/debris particles fly out from the hit point. Same visual family as the existing defeat/break sparkle. No red at all.

B. Red flash tint

Classic NES-style hit flash: the sprite itself pulses red/white. No particles, cheapest to build.

C. Blood splatter — PICKED

A few red pixel droplets scatter from the hit point and fall with gravity, same low-detail retro style as the rest of the game.

D. Burst + flash combo

Both the stylized particle burst AND a brief red flash tint together. More impactful, two effects tuned as one.
